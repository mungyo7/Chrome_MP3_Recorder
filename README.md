# Chrome_MP3_Recorder

현재 탭에서 나오는 소리를 녹음해 다운로드 폴더에 저장하는 Chrome 확장 프로그램입니다.
툴바 아이콘을 한 번 누르면 녹음이 시작되고, 다시 누르면 녹음을 멈추고 파일로 저장합니다.

- 외부 서버로 아무것도 보내지 않습니다. 녹음과 저장은 모두 브라우저 안에서 처리됩니다.
- 녹음하는 동안에도 탭 소리는 스피커로 계속 나옵니다.
- 필요한 권한은 `tabCapture`, `offscreen`, `downloads` 세 가지입니다.

## 요구 사항

- Chrome 116 이상 (`manifest.json`의 `minimum_chrome_version`)

## 설치

웹 스토어에 올리지 않은 로컬 확장이므로 개발자 모드로 불러옵니다.

1. 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더(`tab-audio-recorder`)를 선택합니다.
4. 툴바의 퍼즐 아이콘에서 **Tab Audio Recorder (local)**를 고정해 두면 쓰기 편합니다.

코드를 고친 뒤에는 `chrome://extensions`에서 이 확장의 새로고침 버튼을 눌러야 반영됩니다.

## 사용법

1. 녹음할 탭을 연 상태에서 확장 아이콘을 누릅니다. 아이콘에 빨간 `REC` 배지가 뜹니다.
2. 녹음을 끝내려면 아이콘을 한 번 더 누릅니다.
3. 파일이 다운로드 폴더에 바로 저장되고 배지가 사라집니다. 저장 위치를 묻는 창은 뜨지 않습니다.

녹음 중인 탭을 닫아도 그때까지 녹음된 내용이 자동으로 저장됩니다.

### 배지 의미

| 배지 | 의미 |
|---|---|
| `REC` | 녹음 중 |
| `ERR` | 녹음을 시작하지 못했거나 녹음 중 오류가 남 |
| 없음 | 대기 중 (저장 완료) |

## 저장 파일

- 파일 이름: `<탭 제목>_<YYYYMMDD>_<HHMMSS>.<확장자>`
  - 탭 제목에서 파일 이름에 쓸 수 없는 문자(`\ / : * ? " < > |`, 줄바꿈, 탭)는 공백으로 바꾸고 60자까지만 씁니다.
- 형식: 브라우저가 지원하는 첫 번째 형식을 고릅니다. 비트레이트는 192 kbps입니다.
  1. `audio/mp4` (AAC) → `.m4a`
  2. `audio/webm` (Opus) → `.webm`

> 이름과 달리 MP3로 저장하지는 않습니다. MP3가 꼭 필요하면 저장된 파일을 변환하세요.
> 예: `ffmpeg -i input.m4a -b:a 192k output.mp3`

## 동작 방식

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 (Manifest V3), 권한 선언 |
| `background.js` | 서비스 워커. 아이콘 클릭으로 녹음 시작/중지를 토글하고, 배지를 바꾸고, 다운로드를 실행 |
| `offscreen.html` / `offscreen.js` | 화면에 보이지 않는 문서. 탭 오디오 스트림을 받아 `MediaRecorder`로 녹음 |

1. 아이콘을 누르면 `background.js`가 `chrome.tabCapture.getMediaStreamId()`로 현재 탭의 스트림 ID를 받습니다.
2. offscreen 문서를 만들고 스트림 ID와 저장할 파일 이름을 넘깁니다.
   서비스 워커는 녹음 중에 잠들 수 있어서 녹음과 파일 이름 보관은 offscreen 문서가 맡습니다.
3. `offscreen.js`가 `getUserMedia`로 탭 오디오를 받아 `AudioContext`로 스피커에 다시 내보내면서 동시에 녹음합니다.
4. 녹음이 끝나면 Blob URL을 `background.js`로 보내고, `chrome.downloads.download()`로 저장합니다.
5. 다운로드가 끝나면(완료 또는 중단) offscreen 문서를 닫아 메모리를 정리합니다.

## 제한 사항

- `chrome://` 페이지, Chrome 웹 스토어처럼 캡처가 막힌 탭은 녹음할 수 없습니다. 이때 `ERR` 배지가 뜹니다.
- 한 번에 한 탭만 녹음합니다. 녹음 중에 다른 탭에서 아이콘을 눌러도 새 녹음이 시작되지 않고 진행 중인 녹음이 멈춥니다.
- 녹음 데이터는 저장 전까지 메모리에 쌓이므로 아주 긴 녹음은 메모리를 많이 씁니다.
- 아이콘 이미지를 따로 넣지 않아 Chrome 기본 아이콘(글자 아이콘)으로 표시됩니다.

## 문제 해결

- **`ERR` 배지가 떴을 때**: `chrome://extensions`에서 이 확장의 **서비스 워커** 링크를 눌러 콘솔 오류를 확인합니다. 녹음 중 오류는 offscreen 문서 콘솔에 남습니다.
- **아이콘을 눌러도 반응이 없을 때**: 이전 녹음의 offscreen 문서가 남아 있을 수 있습니다. 확장을 새로고침한 뒤 다시 시도합니다.

## 저작권 안내

이 확장은 탭에서 재생되는 소리를 녹음하는 도구일 뿐입니다. 저작권이 있는 음악·영상·강의 등을 녹음하고 이용할 때의 책임은 사용자에게 있습니다.
녹음한 파일은 개인적인 용도로만 쓰고, 권리자의 허락 없이 공유하거나 배포하지 마세요.
